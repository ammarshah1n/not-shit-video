# Brief and story

Use this small working brief in the VIDEO PROJECT, not as a new process bureaucracy:

- Audience / viewing context / aspect ratio:
- One thing they should feel or understand:
- One product action that proves it:
- Current product source and approved disclosure level:
- Visual direction and one reference:
- Desired duration; can text actually fit?
- Synthetic persona / fixture source:
- Voice, music and asset rights:
- Delivery location; publication separately approved?

## Story shapes

**Day-in-the-life:** one person, coherent dates, phone → desktop → away again. Make every feature serve a concrete moment.

**Pain → product → payoff:** a brief recognisable friction, one legible action, a human outcome. The product must cause the change; do not imply it by a disconnected 'before/after' montage.

**Single proof:** open mid-task, orient, perform the action, hold the result, close. Often stronger than a 12-feature tour.

## Claim table

| Exact claim / screen | Evidence | Status and audience |
|---|---|---|
| The user can perform this action | Current code or observed fixture flow | Shipped / local-only / concept; public / private |

Add only actual claims. Do not fabricate statistics, testimonials, clients, provider names, benchmark wins, latency or functionality. Simulated time compression must be visually honest; timers must follow the simulation. A staged fixture is not a live production transaction.

## Cut plan

For each beat note: start, duration, surface, visible copy, action, completed-result hold, voice and sound. A 30-second cut should select fewer beats from the same vocabulary, not speed the master up. Voice can bridge shots but may never outrun evidence. The title card can be music-only; end card resolves to silence.

## Public marketing boundary

Keep public copy outcome-shaped: what gets easier, what the user receives, how it feels. Do not leak internal prompts, private system architecture or customer information merely because those made a convincing private demonstration. Review every visible sidebar, browser title, URL, file name, tooltip and reflection.
